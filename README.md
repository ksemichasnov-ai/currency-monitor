# Currency Monitor

Бесплатный мониторинг Raiffeisen и публичного Telegram-канала X-Change Винница через GitHub Actions.

## Что отслеживается

- Raiffeisen: USD/UAH и EUR/UAH, покупка и продажа в блоке «У касі банку».
- Telegram: новые публикации публичного канала `@X_Change_Vinnitsa`.
- Интервал: плановый запуск каждые 5 минут (GitHub может задерживать scheduled runs).

## Настройка

1. Создайте Telegram-бота через @BotFather.
2. Откройте созданного бота и нажмите Start.
3. Узнайте свой числовой Telegram ID через @userinfobot.
4. Создайте **Public** репозиторий GitHub и загрузите файлы проекта.
5. В репозитории откройте Settings → Secrets and variables → Actions → New repository secret.
6. Добавьте:
   - `BOT_TOKEN` — токен от BotFather.
   - `CHAT_ID` — ваш числовой Telegram ID.
7. Откройте Actions и разрешите запуск workflows, если GitHub попросит.
8. Запустите workflow вручную через Actions → Currency monitor → Run workflow.

При первом успешном запуске бот пришлёт подтверждение и запомнит текущие курсы/последний пост. Старые публикации канала не рассылаются. Далее будут приходить уведомления об изменениях курса и о новых постах.

## Важно

- Репозиторий публичный, поэтому никогда не добавляйте токен бота в файлы проекта. Используйте только GitHub Secrets.
- Состояние `state.json` сохраняется коммитом в репозиторий. Оно не содержит токенов или личных данных, кроме публичного ID последнего поста и истории текущих курсов.
- Скрипт использует браузер Chromium, потому что страница банка может загружать курсы динамически.
- Если Raiffeisen изменит разметку страницы, извлечение курсов может потребовать обновления функции `fetch_raif_rates` / `parse_pair`. При ошибке смотрите журнал во вкладке Actions.
- Публичная веб-лента Telegram доступна только для публичных каналов и может меняться. Если Telegram ограничит веб-просмотр, потребуется другой способ чтения канала.
- GitHub Actions не гарантирует запуск ровно в минуту расписания.
